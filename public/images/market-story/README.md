# Market story visual assets

Drop files in here — real photos, Canva-style graphics, illustrations,
whatever you've got. Nothing in this folder is required for the Market
page's scrollytelling narrative to work (it's all text + data charts right
now), but the components will pick these up once you add them:

## `photos/`

Suggested slots (any of these can be missing — nothing breaks):

| Filename | Used for | Suggestion |
|---|---|---|
| `skills-act.jpg` | Act 01 · Skills | An engineer at a screen, code, a UK tech-office scene |
| `geography-act.jpg` | Act 02 · Geography | A UK city skyline — London, Cambridge, Edinburgh |
| `velocity-act.jpg` | Act 03 · Hiring Velocity | Something that reads "movement/growth" — an office, a hiring event |
| `salary-act.jpg` | Act 04 · Salary & Sponsorship | An office, a handshake, something that reads "offer/opportunity" |

## `illustrations/`

Anything abstract/generated (Canva exports, custom SVGs, generated art) —
same naming convention, `.svg`, `.png`, or `.webp`.

## Format notes

- Prefer `.webp` or `.jpg`, reasonably compressed (this is a live web page,
  not a print job) — a few hundred KB each is plenty.
- Landscape orientation works best for the sticky visual panel.
